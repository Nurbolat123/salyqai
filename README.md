# Salyq AI — бэкенд

ИИ-бухгалтер для ИП на упрощённом режиме (форма 910.00) в Казахстане.
Стек: Python 3.12, FastAPI, SQLAlchemy 2, PostgreSQL 16.

Сейчас реализованы три базовых модуля:

| Модуль | Пакет | Что делает |
|---|---|---|
| Налоговый движок | `salyq/tax` | Налог по упрощённой декларации за полугодие и соцплатежи ИП за себя. Суммы в тиынах, параметры из конфигурации по годам, пошаговый «след» расчёта |
| Шлюз обезличивания | `salyq/privacy` | Перед отправкой во внешнюю LLM заменяет ИИН, БИН, IBAN, карты, телефоны, e-mail и ФИО на токены `[PERSON_1]` и умеет вернуть исходные значения в ответ модели |
| Выписка Kaspi Business | `salyq/statements` | Разбор XLSX/CSV и загрузка в БД без дублей |

## Запуск

```bash
docker compose up --build          # API на http://localhost:8000, документация — /docs
docker compose run --rm tests      # все тесты, включая тест на реальном PostgreSQL
```

Локально без Docker:

```bash
python3.12 -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"
pytest                                             # тест на PostgreSQL пропускается
TEST_DATABASE_URL=postgresql+psycopg://salyq:salyq@localhost:5432/salyq_test pytest
uvicorn salyq.main:app --reload                    # переменная SALYQ_DATABASE_URL, см. .env.example
```

## Налоговый движок

**Деньги.** Все суммы хранятся в тиынах (`int`, 1 ₸ = 100 тиын), `float` на входе запрещён
(`salyq/money.py`). Умножение на ставку округляется до тиына по правилу half-up.
Суммы к уплате округляются до целых тенге.

**Конфигурация.** Каждый год описан в отдельном файле `salyq/tax/rates/<год>.yaml`: МРП, МЗП,
ставка и допустимый диапазон корректировки маслихатом, распределение налога между ИПН и СН,
лимит дохода (за полугодие или за год), порог по НДС и ставки соцплатежей. При загрузке
файл проверяется pydantic-схемой: доли налогов должны давать в сумме 1, ставка — попадать в
диапазон, год — совпадать с именем файла. В коде нет ни одной ставки.

Чтобы добавить новый год, скопируйте предыдущий YAML и измените значения. При поправках
внутри года повышайте `version`. Флаг `verified: true` ставит бухгалтер после сверки с
НК РК. Пока флаг не стоит, каждый расчёт возвращает предупреждение `CONFIG_NOT_VERIFIED`.

**«След».** Результат содержит `trace` со следующими данными:

- год, версия и sha256 файла конфигурации;
- список шагов: код, описание, формула, входные значения и результат в тиынах и в тенге.

По следу любой расчёт можно повторить вручную. Помимо суммы налога движок выдаёт
предупреждения: о превышении лимита упрощённого режима (`INCOME_LIMIT_EXCEEDED`) и о
превышении порога постановки на учёт по НДС (`VAT_THRESHOLD_EXCEEDED`).

> ⚠️ Значения за 2025 и 2026 годы заполнены по открытым источникам (`verified: false`).
> Их обязательно должен сверить бухгалтер, особенно параметры 2026 года по новому НК:
> ставку 4%, отсутствие СН, годовой лимит в 600 000 МРП, ОПВР 3,5% и порог НДС
> 10 000 МРП.

## Шлюз обезличивания

```python
from salyq.privacy import Anonymizer, assert_clean

a = Anonymizer(known_names=["Иванов Иван"])   # имена из профиля и справочника контрагентов
safe = a.anonymize(prompt).text                # → "ИП [PERSON_1], ИИН [IIN_1] ..."
assert_clean(safe)                             # финальная проверка перед отправкой наружу
answer = a.deanonymize(llm_answer)             # подставить исходные значения обратно
```

- Одно и то же значение получает один и тот же токен, в том числе если телефон записан в разных форматах.
- Таблица соответствий (`a.mapping`) хранится только у нас.
- Принцип — лучше замаскировать лишнее, чем пропустить данные:
  - любое 12-значное число маскируется. Тип ИИН или БИН определяется по контрольному разряду и структуре, остальное получает тип `ID`;
  - номера карт, в том числе маскированные, маскируются без проверки по алгоритму Луна.
- ФИО распознаются в нескольких видах:
  - по русским и казахским отчествам (-ович, -овна, -ұлы, -қызы, «улы» отдельным словом);
  - по инициалам («Ахметова А.Б.», «А.Б. Ахметова»);
  - по контексту («ИП …», «получатель: …»);
  - по списку `known_names`.
- Ограничение: имя без отчества и без контекста (например, «Айгуль Сапарова» посреди фразы)
  не распознаётся. Поэтому в `known_names` нужно передавать ФИО владельца и контрагентов из БД.

## Выписка Kaspi Business

- Форматы: XLSX и CSV (UTF-8 или cp1251; разделитель `;`, `,` или табуляция). PDF пока не поддерживается.
- Строка заголовка находится автоматически, колонки определяются по синонимам
  (`COLUMN_ALIASES`). Суммы поддерживаются в двух видах: раздельные «Дебет/Кредит» или
  одна колонка «Сумма» со знаком.
- Номер счёта (IBAN) берётся из «шапки» выписки или передаётся явно.
- Строки, которые не удалось разобрать, не прерывают импорт. Они возвращаются в `skipped`
  с номером строки и причиной. Итоговые строки пропускаются.

**Дедупликация.**

1. Внутри файла повтор с тем же номером документа, датой и суммой отбрасывается.
2. Для каждой операции считается отпечаток: sha256 от счёта, даты, направления, суммы,
   номера документа, контрагента, его ИИН/БИН и счёта, КНП, назначения платежа и
   порядкового номера среди полностью одинаковых строк файла.
3. В БД на пару `(account_id, fingerprint)` стоит уникальное ограничение, вставка идёт
   через `INSERT … ON CONFLICT DO NOTHING`.

В результате:

- две реально разные, но одинаковые на вид операции (например, две продажи Kaspi QR на одну сумму в один день) сохраняются обе;
- повторная загрузка того же файла добавляет 0 строк;
- выписки за пересекающиеся периоды не создают дублей.

Пограничный случай: если группа одинаковых операций без номера документа попала в два
файла не целиком (выписка обрезана посреди дня), возможен лишний дубль. Это
ограничение текущей реализации.

## Структура

```
salyq/
  money.py            тиыны, разбор и округление
  tax/                config.py (схема и загрузка YAML), engine.py, trace.py, rates/*.yaml
  privacy/            gateway.py (детекторы и Anonymizer), validators.py (ИИН/БИН, IBAN, Луна)
  statements/         kaspi.py (парсер и отпечатки), repository.py (сохранение с дедупликацией)
  models.py, db.py    SQLAlchemy: bank_accounts, statement_imports, bank_transactions
  api/                роутеры FastAPI
tests/                pytest; fixtures/ — синтетическая выписка (данные вымышлены)
```
